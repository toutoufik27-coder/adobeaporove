# Kiko & Friends · استوديو الإنتاج

خطتك (`kids.html` و`kids-training.html`) مكتوبة كبرنامج Python واحد: `studio`.
الكود يقرّر ما يمكن قياسه، وClaude يكتب ويراجع فقط، والإنسان يحكم على ما لا يُقاس (الاختيار الأعمى للصوت، وانتقاء صور LoRA).

```
bible/                 مصدر الحقيقة: الشخصيات الست، العالم، الصيغ، المنهج، المعاجم، الثقافات
studio/
  bible/               نماذج صارمة (pydantic) + «قانون التصميم» عبر الملفات
  gates/idea.py        البوابة 0: الفكرة يختارها الكود (حصص، دروس، قيم، تدوير البطولة)
  gates/text.py        البوابة 1: النص، لكل لغة (كلمات ممنوعة، طول الجمل، المفردات، طول الدبلجة)
  gates/novelty.py     بوابة التكرار: ضد سياسة يوتيوب للمحتوى «المكرر والمنتَج بالجملة»
  gates/assembly.py    البوابة 5: الفيديو النهائي (الومضات، الجهارة، إيقاع القطع، الكلمات المسموعة)
  writer.py            الكاتب: مسودة ← بوابات ← مراجعة ← ترجمة ← حفظ في السجل
  llm.py               Claude: عبر `claude` (اشتراكك) أو عبر الـAPI
  voice.py             الصوت: المستويات 0–2، فحص التشابه وWhisper، 3 محاولات ثم تعليم للإنسان
  lora.py              الشكل: بيانات kohya، الأوصاف، القلب للمتناظر فقط، الخطوات، شبكة التقييم
  timing.py            الصوت أولًا: مدة كل لقطة من سطورها + سلّم الدبلجة بدرجاته الأربع
  lipsync.py           Rhubarb: تنظيف الجدول، X في الصمت، مفاتيح الفم، هزّة الرأس مع التشديد
  performance.py       خطة اللقطة لـBlender: الإشارة قبل الكلام بـ4 إطارات، الإيماء، الحاجبان، الرمش، وشاح Mira
  media/mix.py         أوامر FFmpeg: المزج مع خفض الموسيقى تحت الكلام، التسوية، التركيب، مسارات اللغات
  media/probe.py       قياسات البوابة 5 من الفيديو
  gpu.py               البطاقتان 3090: قفل لكل بطاقة، الذاكرة، التدريب ليلًا والتوليد نهارًا
  models_guard.py      حارس الرخص بطبقاته الأربع
  ledger.py            ledger.db: ما صُنع وكيف أدّى
  cli.py               الأوامر
tests/                 128 اختبارًا + نص حلقة تجريبية (pilot) بالإنجليزية والإسبانية
```

## مسار الحلقة

```
studio idea next            البوابة 0: الصيغة حسب حصتها، درس لم يُستعمل في آخر 15، قيمة ≤ 20%، البطل بالتدوير
studio write                Claude يكتب → البوابة 1 + التكرار → (أخطاء؟ يعود إليه، 3 جولات)
                            → البوابة 2 (السلوك مع الـbible) → البوابة 3 (مراجع مستقل لم يرَ التعليمات)
                            → ترجمة لكل لغة مفعّلة → البوابة 1 بتلك اللغة → episodes/ep_0001/episode.json
voice.voice_episode         Chatterbox سطرًا سطرًا → Resemblyzer ≥ 0.75 وWhisper → lengths.json
studio plan EP LENGTHS      التوقيت + shots.json الذي يقرؤه Blender
Rhubarb → lipsync           أشكال الفم لكل سطر ولكل لغة
Blender                     الجسم مرة، وطبقة الفم لكل لغة
media/mix                   مزج كل لقطة ← ضم ← تسوية الحلقة إلى −14 LUFS بمرورين ← تركيب ← مسارات اللغات
gates/assembly              الومضات، الجهارة، القطع، الكلمات ← النشر
```

## الأوامر

```bash
pip install -e ".[dev]"
studio bible check                 # قانون التصميم على الـbible كله (الآن: 0 أخطاء، 7 تنبيهات)
studio simulate --episodes 120     # هل يكفي المنهج؟ تخطيط 120 حلقة متتالية
studio idea next
studio write --backend cli         # باشتراك Claude: مرة واحدة `claude login`
studio write --backend api         # بالـAPI: pip install -e ".[api]" وضع ANTHROPIC_API_KEY في متغيرات البيئة
studio gate text episodes/ep_0001/episode.json
studio plan episodes/ep_0001/episode.json episodes/ep_0001/audio/en/lengths.json
studio guard scan                  # يوقف الخط إن وُجد اسم نموذج ممنوع في الكود أو الإعدادات
studio models install all          # pip install -e ".[models]": يقرأ الرخصة قبل التنزيل
studio models verify               # بصمة sha256 لكل نموذج مقفل
studio gpu status
studio gpu run render sh_014 -- blender -b base_rig.blend -P animate_shot.py -- --shot sh_014
studio gpu run --any-time render sh_014 -- ...   # خارج نافذته (الذاكرة تُفحص دائمًا)
```

مفتاح الـAPI لا يُكتب في أي ملف ولا في المحادثة: ضعه في متغيرات البيئة فقط.

## البطاقتان (2× RTX 3090)

| العمل | البطاقة | الذاكرة التقديرية | الوقت |
|---|---|---|---|
| LoRA لـKiko وTuka وZuzu | GPU 0 | البطاقة كاملة | ليلًا |
| LoRA لـBeni وMira وNilo | GPU 1 | البطاقة كاملة | ليلًا |
| تدريب RVC | GPU 1 | البطاقة كاملة | ليلًا |
| الصور، التقطيع، تصميم الصوت، الرندر | GPU 0 أولًا | 11 / 6 / 5 / 4 GB | نهارًا (تصميم الصوت أي وقت) |
| الأصوات وWhisper | GPU 1 أولًا | 6 / 6 GB | أي وقت، بجانب الرندر |

كل بطاقة لها ملف حالة مقفل (`runtime/gpu0.json`)، فلا يظن سكربتان أن البطاقة فارغة في اللحظة نفسها، وتُنسى مهام العمليات الميتة تلقائيًا. أرقام الذاكرة تقديرات بداية: قِسها بـ`nvidia-smi` وعدّلها في مكان واحد (`studio/gpu.py`).

## ما صُحّح في الخطة أثناء كتابتها

هذه ليست إضافات: كل واحد منها خطأ وجده الكود أو الاختبارات في الخطة نفسها.

1. **قيم طبقة الصوت تخالف قاعدة الخطة نفسها** («لا تتقارب شخصيتان في الطبقة والسرعة معًا»): Beni وMira كلاهما +3 وبطيء، وKiko (+4) وZuzu (+5) كلاهما سريع ويفصلهما نصف نغمة. القيم الآن: Kiko +3 سريع، Beni +2 بطيء، Tuka +2 متوسط، Mira +4 بطيء، Zuzu +5 سريع، Nilo 0 بطيء. وفي الاختبارات اختبار يثبت أن القيم الأصلية ترسب.
2. **Mira تعني «انظر!» بالإسبانية**: كل «¡Mira!» في الحوار ستُسمع كاسمها. يبقى تنبيهًا لتقرّره أنت. وعبارة Nilo الإسبانية تغيّرت من «Mira…» إلى «Fíjate… justo aquí.».
3. **15 درسًا لا تكفي للإطلاق**: عند الإطلاق صيغة واحدة، والدرس لا يتكرر في آخر 15 حلقة، فيتوقف الإنتاج عند الحلقة 16. أصبح المنهج 75 درسًا، و`studio bible check` يحاكي كل مرحلة من الإطلاق ويرفض أي منهج ينفد.
4. **±15% بعدد المقاطع ترفض الإسبانية الصحيحة**: الإسبانية تنطق مقاطع أكثر في الثانية. صار القياس بزمن النطق التقديري، والعبارات الثابتة للشخصيات لا تُحسب، والسطور القصيرة جدًا تقارَن بهامش مطلق.
5. **تسوية الجهارة لكل لقطة** تجعل اللقطة الهادئة بصخب المزدحمة وتضخّ الموسيقى بين اللقطات. صارت التسوية مرة واحدة للحلقة كلها بمرورين (قياس ثم كسب خطي).
6. **فحص الأسماء الممنوعة بالحروف فقط كان سيوقف Chatterbox**: «ChatterboxTTS» تحوي «xtts». صارت المطابقة على بداية الكلمة، مع اختبار لهذه الحالة.
7. **الرخصة تُقرأ من commit، والتنزيل يُثبَّت عليه**: فلو غيّر مستودع رخصته لاحقًا لا يدخل التغيير.
8. **الحلقة كانت ستكون كلامًا فقط**: التوقيت يُبنى من السطور، فتحتاج حلقة 6 دقائق نحو 110 سطور متتالية. أُضيف `hold_s` (حركة بلا كلام بعد السطر)، وتقدير لطول النص في البوابة 1 قبل توليد أي صوت.

## ما تم التحقق منه، وما لم يُشغَّل هنا

- **128 اختبارًا تنجح.** منها 3 تشغّل FFmpeg حقيقيًا: المزج مع الخفض والتسريع ثم التسوية إلى −14 LUFS، واكتشاف ومضات بـ5 هرتز وقطع حقيقي من فيديو، وتركيب طبقة الفم ومسارين صوتيين. وتُتخطى هذه الثلاثة تلقائيًا إن لم يكن FFmpeg مثبّتًا.
- **طلب الـAPI** بُني عبر مكتبة Anthropic الحقيقية (1.8.0) دون إرساله: `claude-opus-5`، مخرجات منظّمة، تفكير تكيّفي، تخزين مؤقت لتعليمات الـbible، و`fallbacks: "default"`.
- **لم يُشغَّل هنا لغياب GPU وBlender وRhubarb**: محوّلات Chatterbox وParler-TTS وResemblyzer وWhisper في `voice.py` (مكتوبة مثل أمثلة خطتك تمامًا لكنها غير مجرّبة)، وأمر kohya، وRhubarb نفسه. منطق كل واحد منها مختبَر ببدائل وهمية، أما النماذج نفسها فتُجرَّب على جهازك.
- **لم يُكتب بعد**: سكربت Blender `animate_shot.py` لأنه يحتاج الدمى أولًا (الأسابيع 10–15 من جدولك). عقده جاهز: `shots.json` من `studio plan`. ولم تُكتب كذلك البوابة 4 (الصورة): تقييم LoRA حكم بشري بحسب خطتك، والكود يجهّز له الشبكة الثابتة (8 برومبتات × 4 بذور).
