# أدوات الأيقونات

| الأداة | الوصف |
|---|---|
| [`prompts/`](prompts/) | مولّد البرومبتات: «ماذا أصنع الآن؟» حسب تقويم المناسبات، برومبتات صارمة لـ Google Flow، محرك أفكار، عناوين وكلمات مفتاحية وملف CSV لـ Adobe Stock. |
| [`vectorizer/`](vectorizer/) | محوّل الصور إلى SVG: يعيد رسم الأيقونات، يحذف الخلفية، يفصل كل أيقونة في ملف مستقل، ويصنع لوحة أيقونات للعرض. |
| [`refine/`](refine/) | منظّف الفيكتور: يحلل ملف SVG ويعيد بناء هندسته بأمان، ويعيد الحواف إلى مكانها في الصورة الأصلية، ويصحح أخطاء المعنى بنموذج ذكاء اصطناعي محلي. |

**سير العمل:** مولّد البرومبتات ← Google Flow ← محوّل الفيكتور ← منظّف الفيكتور ← ملفات SVG جاهزة للبيع.

**التشغيل:** في جذر المشروع شغّل `python3 -m http.server 8000`، ثم افتح `http://localhost:8000`. الأدوات الثلاث تعمل من نفس العنوان، لأن الربط بينها يمر عبر ذاكرة المتصفح.
